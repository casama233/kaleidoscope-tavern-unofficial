# A11 仍受阻的美術範圍

A11 沒有新增上游原始模型／貼圖檔案，這一輪專注在 **已取得來源** 的姿態檢視補強。

## 仍受阻範圍

- 其他家具：高腳凳、桌、人字梯
- 燈具與香薰：吊燈、彩燈、香薰／粒子
- 畫與板類：畫、黑板、告示牌、可能涉及文字內容的板件

## 為什麼這輪沒有直接補上

目前專案內 `upstream/` 與 `sources.lock.json` 尚未包含這些家族的 **原始 Java 模型 JSON / 對應貼圖 PNG**。
在沒有取得正確來源前，本批次不會自行猜測結構、重繪貼圖或拿不相關模型冒充完成。

## A11 實際推進了什麼

- 把現有來源中帶有 `display` 數值的外觀整理成 PoseLab 索引。
- 補上 `kt_a11/*` 姿態給物品函數，方便在遊戲中分組驗收。
- 產出 `docs/A11-POSE-SUMMARY.json` 與 `previews/pose-gallery.html`，讓剩餘姿態範圍更容易核對。

## 下一步建議

1. 先補抓上述受阻類別的原始來源檔。
2. 來源到位後，再開 A12 之類的批次做家具／燈具／板件移植。
3. 真機驗收時，把 PoseLab 疊在主 RP 上方，先檢查 GUI、ground、first/third person 是否偏移。
