## 來源核對

18份來源檔：9個Java JSON模型、1個Java ModelPart源碼、6張PNG、2份授權文件。

所有來源內容以Git blob SHA-1和本地SHA-256核對。正式JAR仍未取得，提交與正式發行檔的一致性不是已完成項。

## 座標與UV

Java JSON 模型以原點平移到 X/Z 中心，按照 Bedrock/Blockbench 既有慣例處理 X、旋轉和上下面 UV。保留有向 UV 長度、90度增量的 UV 旋轉以及原作欠缺的面。所有零厚度面均保留。

酒桶使用 ModelPart 的相對骨架，轉成絕對未旋轉 pivot 加父子骨架。北向的原作顯示變換納入資源轉換；尚未實作遊戲狀態控制朝向。完整骨架中 open/close 為互斥顯示分支。

10個已轉出模型均進行「輸出geometry → 解碼 → 面頂點與UV數值比較」檢查。這只能驗證轉換器沒有遺失這些數值，不代表對所有引擎渲染慣例的獨立證明。離線圖片是geometry解碼後的軟體光柵預覽，不是遊戲截圖。
