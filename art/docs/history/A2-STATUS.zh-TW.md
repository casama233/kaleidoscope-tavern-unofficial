## 數量與來源

- 62 份原始檔：A1 18 + A2 44。
- A2 新增44份：29個Java JSON、14張PNG、1個動畫mcmeta。
- 原作 PNG 累積20張，原圖位元組未變；另外12張動畫拆幀是衍生檔。
- Bedrock幾何39個；Blockbench編輯檔41個。
- 展示方塊37個、展示實體2個、圖示物品10個。

## 此次修正／保留的格式細節

1. Java `rescale=true` 的45度葉片按原始 pivot 烘焙垂直於旋轉軸的縮放，避免漏掉旋轉補償。
2. 葡萄藤第2階段水平反向UV保留；藤架90/180/270度UV旋轉亦保留。
3. 交叉零厚度薄片未改成實心方塊，未自行收縮超出單格的頂點。
4. 原作 `shade=false` 以獨立材質面設定表達；最終光照和材質效果仍待引擎驗證。
5. 冰葡萄完整12幀原圖、拆幀和2tick時間／插值旗標保留。遊戲圖示明確使用首幀，不宣稱已支援原作背包動畫。
6. A1的10個幾何和12個編輯檔與A1包逐位元組比較不變；A2的套件版本提高到[0,3,0]，保留既有UUID供更新辨識。

## 檢查範圍

`VALIDATION.json` 記錄每個檢查結果。除了格式和引用，另從未改動的Java源模型獨立重算旋轉／縮放後頂點，与匯出幾何解碼結果比較。這比只做JSON解析更能發現資料遺失，但**仍不能當成對Bedrock渲染慣例的遊戲實測證明**。

`previews/index.html`、PNG及WebP皆是離線檢查圖，並非遊戲截圖或動畫錄影。實體位置、透明雙面、手持、物品欄與碰撞等需要人工驗收。

## 持續存在的發行阻擋

正式發布JAR未比對；Cookery身份與版本未綁定；Minecraft／bridge／Blockbench互動式載入未做；空瓶幾何尚未解除；其餘原作資源未搬完。因此本包只能是資源階段的中間成果，不能當作正式Tavern移植版。
