# C6 遊戲驗收清單 — 全部 NOT_RUN

**這是待執行清單，不是通過報告。** 每項記錄遊戲版本、裝置/控制方式、世界副本、Content Log、實際結果與畫面。Node替身不驗證Molang、坐姿、亮度、原生扣量或網路。

## 1. 載入與資料隔離

新世界啟用Cookery v1.0.6 BP/RP與C6 BP/RP，不開舊VisualLab/PoseLab。檢查11個block custom components、33新增家具物品、16座位entity、所有幾何/動畫/材質引用，不得有整包跳過或缺元件。指南、配方書仍獨立，Cookery原書、偏好與配方不變。兩個示範附屬按需測，全部啟用時43機器配方，核心仍41。

## 2. 全十六色高腳凳

`/function kt_c6_all_stools`只給16物件，需預留16欄。每色潛行點支撐顶面放置，核對完整底座/座墊/靠背/扶手/腳踏；下方必須允許完整支撐，上一格不夠空間拒絕。對4個玩家朝向擺放，凳面應與原作opposite-player規則一致。

空手點坐下，核對原生player坐姿、雙腿和Steve/Alex高度是否合理；記錄.8125候選是否需修。轉向跨過179/-179，檢查只轉上層、不卡轉/長圈、底座不跟著轉。第三人稱另一玩家應看到相同轉動。潛行離座、控制器/觸屏的離座按鍵、原生dismount是否卡牆都需單測。

兩人搶一席只能成功一人；已在船/馬上不切走原坐騎。有人乘坐時潛行回收與挖掘都拒絕；人離開後可回收。滿背包回收取消，不得只刪椅子。Creative放1扣1，取1返1。

離開區塊、重開世界後凳子仍在且只一個helper；occupied重連、死亡、跨維度不得留下鬼乘客。只移除helper，凳方塊稍後應重建；用命令換掉方塊，孤立helper要退人並消失、**不得補發一件家具**。未載入不能被當空氣誤清。

## 3. 全十七款彩燈

`/function kt_c6_all_lights`需17空欄。每款確認不是藍色換皮、各自薄片及UV正確。四方向尤其正背/側面、手持圖示透明背景均核對。暗室比較亮度15是否生效；不要求RGB染色光或紅石開關。

各色原生染料換型：消耗1個，保持朝向，換成該款自己的模型。相同顏色不扣。回收/挖掘得到1當前款，背包滿取消。重載後顏色/朝向不變。無色款由配方獲得，不測不存在的漂白功能。水浸/支撐移除自然落下目前不是已完成項。

原生合成冊驗證33配方：凳羊毛/鎖鏈/鐵錠豎列產1；彩燈兩排3鎖鏈+3燈籠產8，彩色加第三排3染料仍產8。

## 4. 聲波：只在空曠試驗場

**不要对準宠物、村民或建築內的生物，穿牆且可能傷害非敵對動物。** 以受控測試目標測32格、半寬邊界、後方不命中、斜向與垂直、穿牆。施用者當前20生命→基礎24、10生命→12，保持原生sonicBoom伤害與抗性/無敵結果；不是直接setHP。

拒傷目標不得仍被強制擊退。已有速度與新impulse相加，向上.28/水平.63；粒子16點與聲音只一輪。同線路另一玩家不得受傷/擊退；本包visual helpers、XP球不得被打壞。多於256命中要有可查限額診斷。

生存持一杯/整疊幽匿特調喝完，應原生扣1返1空杯，聲波回呼不得第二次扣/返。Creative也測，但不假設與生存完全一樣。原native傷害觸發血腥瑪麗等既有事件時不重複死亡回復。

## 4.5 螺絲起子／倒立效果

以生存玩家喝完一杯螺絲起子；16格膨脹AABB內的普通存活生物應被命名為 `Grumm` 並由原生彩蛋倒立。測試AABB角落、剛好邊界、邊界外、死亡生物、另一名玩家及本包座位helper；玩家自身與非mob不得被改名。重新載入後名稱應依原生實體名稱持久化規則保留。

Java原作另呼叫 `setCustomNameVisible(false)`；Bedrock Script API沒有通用直接對等項，因此需記錄名稱牌實際顯示方式。這一點在實機確認前仍是明示差異，不能只用Node替身判定完成。

## 4.6 莫希托／靈視效果

喝下莫希托後，用普通生物、另一名玩家與不同大小目標測試6格半徑；目標新進入範圍時應取得60 tick Glowing，既有Glowing目標仍刷新時長但不重播靈視音效。等待下一個50 tick節點後確認持續刷新；離開範圍後不再續時，讓原生Glowing自行結束。

另以測試資料注入 amplifier 1/2，確認半徑12/18且2以上封頂18。測AABB邊界與角落，不應退化成單純球形距離。記錄原作 `effect.vision` 音效在單人／多人客戶端的可聽範圍，以及發光描邊對玩家與各類生物的實際表現。C6沿用5tick巡檢，因此pulse允許比Java精確tick最多晚一個巡檢窗口，但不可漏掉50tick節點。

## 4.7 下界特調／摸金校尉

喝下下界特調後，分別攻擊 Skeleton、Stray、Wither Skeleton、Bogged、Skeleton Horse、Zombie、Zombie Villager、Drowned、Husk、Piglin、Piglin Brute、Zombified Piglin、Vindicator、Pillager、Witch。對能持主手物品的目標反覆測試，長期觸發率應接近30%；Creeper、Evoker等不在來源tag的生物不得被卸裝。

觸發時確認主手立刻清空，原物品的名稱／附魔／其他metadata保持；有耐久物應只剩1耐久，無耐久或Unbreakable物品不應被偽造耐久。掉落物立即可見，但前40 tick任何玩家／生物拾取都應被阻止，第40 tick後可正常拾取。測試物品生成失敗/區塊邊界時不得默默刪除原武器。

特別測致死一擊、弓箭／投射物、多人同時攻擊與重載。Java使用Forge `LivingHurtEvent`，Bedrock使用 `entityHurt` after-event；若致死一擊時Bedrock已使實體無效，需記錄並決定是否另做before-event安全適配。C6自訂效果目前只有玩家持有，不宣稱任意生物 `/effect` 等價。

## 5. C5 及之前功能回歸

至少走一次種植→壓榨→釀造→Q4投料→拿起雪克杯→原生長按/鬆手→倒入已放空杯→擺取特調→飲用。16空桶/空杯交換保留15；退藥水保留effect/delivery，不變水瓶；本輪不得讓家具beforeEvent吃掉原機器互動或其他包已取消事件。

原生長按是否真的觸發、remaining ticks、111tick watchdog、Steve/Alex手腕與杯嘴、不同FOV/手機/控制器、透明排序仍是未驗收門檻。指南切換fallback只驗fallback，不算native成功。牛奶/死亡清自訂持續效果、離線暫停、原生返瓶/返杯也需實機。
